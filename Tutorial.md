requisites:You need Python 3.x installed on your system to run this tool./ first execute this command in the cmd: pip install langdetect deep-translator/ then Create a new dedicated folder.Move your translate.py script and your .ct file inside that folder. then Right-click translator.py and select "Open with Python". If everything is set up correctly, the program will automatically detect the .ct file.Wait a few minutes (the exact time depends on the size of your file).Once finished, the tool will generate the new translated .ct file in the same folder.
