First in cmd execute: pip install langdetect deep-translator then
Create a new dedicated folder.Move your translator.py script and your .ct file inside that folder.Run the script using either of these methods:Method A: Right-click translator.py and select "Open with Python".Method B: Open your terminal in that directory and run:python translator.py
.If everything is set up correctly, the program will automatically detect the .ct file.Wait a few minutes (the exact time depends on the size of your file).Once finished, the tool will generate the new translated .ct file in the same folder.
